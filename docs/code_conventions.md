# Script Conventions

This file describes the convention used.

## Naming Conventions

### ALL CAPS

All capital functions are in /libs/common and are considered global or are spawned into separate processes.

### Underscore

Underscore functions are file specific internal.

### Lowercase

All lowercase functions are folder level public.

## Script Sections

### INTERNAL

These sections are script specific functions.

### EXTERNAL

These sections are spawned into sub processes
